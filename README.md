Este repositorio contiene todo el código y los laboratorios de software de [MIT Introduction to Deep Learning](http://introtodeeplearning.com). Todas las diapositivas y videos de las clases están disponibles en el sitio web del programa.

# Instrucciones
Los laboratorios de software de MIT Introduction to Deep Learning están diseñados para ser completados a tu propio ritmo. Al final de cada laboratorio, habrá instrucciones sobre cómo puedes enviar tus materiales como parte de las competencias del laboratorio. Estas instrucciones incluyen qué información debe ser enviada y en qué formato.

## Abrir los laboratorios en Google Colaboratory:

Los laboratorios de Introduction to Deep Learning 2026 se ejecutarán en Google Colaboratory, un entorno de notebooks Jupyter que se ejecuta completamente en la nube, por lo que no necesitas descargar nada. Para ejecutar estos laboratorios, debes tener una cuenta de Google.

En este repositorio de Github, navega a la carpeta del laboratorio que deseas ejecutar (`lab1`, `lab2`, `lab3`) y abre el notebook de Python correspondiente (\*.ipynb). Haz clic en el enlace "Run in Colab" en la parte superior del laboratorio. ¡Eso es todo!

## Ejecutar los laboratorios
Ahora, para ejecutar los laboratorios, abre el notebook de Jupyter en Colab. Navega a la pestaña "Runtime" --> "Change runtime type". En la ventana emergente, en "Runtime type" selecciona "Python 3", y en "Hardware accelerator" selecciona "GPU". ¡Recorre los notebooks y completa las celdas `#TODO` para que el código compile por ti mismo!


### Paquete MIT Deep Learning
Puede que notes que dentro de los laboratorios instalamos el paquete de Python `mitdeeplearning` desde el repositorio de paquetes de Python:

`pip install mitdeeplearning`

Este paquete contiene funciones de utilidad que usamos a lo largo del curso y se puede importar como cualquier otro paquete de Python.

`>>> import mitdeeplearning as mdl`

Hacemos esto por ti en cada uno de los laboratorios, pero el paquete también es de código abierto bajo la misma licencia, por lo que también puedes usarlo fuera de la clase.
